Front page & insights

An optional newspaper “front page” above the inbox. It reads only the messages currently loaded in your list — nothing leaves your browser.

Backup & presets

Export saves your whole layout to a file you can re-import later. Presets store named looks you can switch between in one click.

Full backup also includes your sender rules, sender colours, pinned labels and saved presets.

Pinned labels

Pin favourite custom labels so they float to the top of the sidebar. Type the label’s name (the leaf name, e.g. PayPal).

Sender colours

Pin a colour for a sender’s tile — it overrides the fetched logo with a clean coloured letter. Use the domain, e.g. paypal.com.

Sender rules

Tag a sender by domain to change how its mail looks in the inbox: VIP pins a gold edge and bold name, Mute dims it and drops the “new” emphasis, Hide removes it from the list. All reversible — remove the rule to undo. Use the domain, e.g. newsletters.com.

Saved views

Save a named Gmail search you can jump to from the front-page bar. Use any Gmail search, e.g. is:unread from:boss@work.com or has:attachment newer_than:7d. Needs the front page enabled to show the buttons.

Auto-sort inbox (optional companion)

Automatically label incoming mail with the companion Google Apps Script. It runs inside your own Google account — GmailView never sees your mail.

Open Google Apps Script ↗
  1. Click the button above → start a New project.
  2. Paste the script from your project folder 11_Auto_Sorter/LabelSorter.gs.
  3. Keep DRY_RUN = true to preview in the logs, then set it to false.
  4. Run once to authorize, then add a time-based Trigger (e.g. every 15 minutes).
